# 🎯 Foco - Mobile App

O **Foco** é um aplicativo mobile multiplataforma (Android/iOS) desenvolvido com React Native e Expo focado em otimizar a rotina de estudos de alunos universitários e de cursos preparatórios, conectando-os a mentores para validação de cronogramas.

## 🛠️ Pré-requisitos
* Node.js v18 ou superior instalado
* NPM ou Yarn
* Expo Go instalado no smartphone (para testes em ambiente real)
